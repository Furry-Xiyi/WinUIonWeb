# WinUI on Web 🌐
是一个把 [WinUI](github.com/microsoft/microsoft-ui-xaml) 带到网页的项目，你可以使用我写的控件直接在网页上使用 **WinUI 控件**。
控件具有完整的动画与材质，还原度达到 **90%**

### 声明

本项目是对 Microsoft [WinUI](github.com/microsoft/microsoft-ui-xaml) 的 Web 实现，旨在使用 Vue 在 Web 平台上复现 WinUI 的外观与交互体验。

本项目未直接使用 Microsoft WinUI 的任何源代码，所有代码均为独立实现。

本项目与 Microsoft 无任何关联，亦未获得 Microsoft 的认可或授权。
